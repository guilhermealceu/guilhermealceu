## 👋 Sobre mim

Trabalho com **infraestrutura, segurança e automação há mais de 10 anos**: firewalls, servidores, virtualização, monitoramento e suporte a várias empresas ao mesmo tempo. Boa parte do que está aqui nasceu de um problema real do dia a dia, que eu resolvi com código.

No tempo livre construo o ecossistema da **[RUNE Projects](https://www.runeprojects.com.br)**: apps, jogos, música e narrativas, com a **Nixie** como personagem que atravessa esse universo. Os apps para desktop chegam pelo **[RuneHub](https://runehub.runeprojects.com.br/)**, um launcher para Windows com atualização automática.

```yaml
foco:        [infraestrutura, segurança, automação, IA local]
dia_a_dia:   [pfSense, Proxmox, Zabbix, GLPI, Windows Server, Microsoft 365]
construindo: [RUNE Projects, RuneHub, Nixie]
lema:        "O tempo só para se você não evoluir!"
```
